# Irmandade - Rede Social Cristã

## Sobre o Projeto

O **Irmandade** é uma rede social exclusiva para membros da Congregação Cristã no Brasil (CCB). O app conecta a irmandade, permitindo compartilhamento de fé, orações, eventos, estudos bíblicos e muito mais.

## Funcionalidades Principais

- **Feed de Posts**: Compartilhar reflexões, orações, fotos e vídeos
- **Stories**: Atualizações diárias que desaparecem em 24h
- **Mensageiro**: Chat privado e em grupo (estilo WhatsApp)
- **Grupos**: Comunidades por congregação, região e interesse
- **Eventos**: Criação e gerenciamento de eventos da igreja
- **Vídeos Curtos**: Reels estilo TikTok
- **Namoro Cristão**: Encontros para relacionamentos sérios
- **Marketplace**: Compra e venda de produtos
- **Página Profissional**: Perfil comercial para membros
- **Sistema de ADS**: Anúncios para páginas profissionais
- **Pedidos de Oração**: Pedidos e intercessões
- **Hinário Digital**: Todos os 450 hinos da CCB
- **Bíblia Online**: Bíblia completa com múltiplas versões

## Como Executar

### Pré-requisitos
- Node.js 18+
- PostgreSQL 14+
- Redis

### Backend
```bash
cd backend
npm install
npm run dev
```

### Mobile
```bash
cd mobile
npm install
npx react-native run-android
# ou
npx react-native run-ios
```
